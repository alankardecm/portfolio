# Portfólio de Alan Moreira

Site estático em HTML, CSS e JavaScript. Identidade alinhada à AM Consultoria: dados, processos e IA aplicados à operação.

## Executar localmente

```bash
python3 -m http.server 8000
```

Acesse http://localhost:8000. Não há dependência de build. A fonte externa tem fallback para fontes do sistema.

## Organização

- `index.html`: conteúdo, navegação e metadados.
- `css/style.css`: identidade, layout responsivo e acessibilidade.
- `js/main.js`: navegação, filtros e integração de contato onde aplicável.
- `docs/REFORMULACAO.md`: direção editorial, integrações e validações de publicação.

## Publicação

Hospedagem Vercel com a configuração estática existente. Revisar o preview antes de integrar a branch em main.
